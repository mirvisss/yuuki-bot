# Юки в облаке — как это работает и что делать дальше

Бот запущен бесплатно, без банковской карты. Схема:

```
GitHub (код) ──► Render (запускает бота 24/7, free-инстанс, Docker)
                    ▲
GitHub Actions ─────┘  раз в 10 минут пингует бота, чтобы Render его не усыплял
База данных: Aiven PostgreSQL — та же, что и раньше (данные не потерялись)
```

## Что уже сделано

| Что | Где | Значение |
| --- | --- | --- |
| Код | GitHub | `mirvisss/yuuki-bot`, ветка `main` (репозиторий публичный) |
| Бот | Render | сервис `yuuki-bot`, тип **Docker**, план **Free**, регион Frankfurt |
| Адрес бота | Render | https://yuuki-bot-iu6b.onrender.com |
| Переменные окружения | Render → Environment | `BOT_TOKEN`, `CLIENT_ID`, `DATABASE_URL`, `GROQ_API_KEY`, `SERPAPI_API_KEY`, `BYTEZ_API_KEY`, `TENOR_API_KEY`, `BOT_LOCALE=ru` |
| База данных | Aiven | берётся из `DATABASE_URL`; таблицы уже созданы |
| Не спать | GitHub Actions | `.github/workflows/keepalive.yml` — пинг раз в 10 минут |
| Не спать | код бота | `src/lib/keepAlive.js` — самопинг каждые 5 минут + healthcheck на порту Render |

## Как убедиться, что бот жив

1. Откройте https://yuuki-bot-iu6b.onrender.com — должно быть написано `Yuuki is running`.
   Первый открытый запрос после долгой паузы может занять до 50 секунд — это нормально.
2. В Discord бот должен быть в сети (в логах он показан как `Yuuki#3831`).
3. Render → ваш сервис → **Logs** → последняя строка должна быть `Система в сети · Юки работает`.
4. GitHub → вкладка **Actions** → workflow **Keep-alive** → там должны быть успешные запуски.

## Что важно знать про бесплатный тариф Render

- **750 часов работы в месяц бесплатно.** Один работающий сервис — это ~730 часов.
  Второй бесплатный веб-сервис займёт остаток квоты, и бот будет остановлен до следующего месяца.
- **512 МБ памяти.** Если после большого обновления бот начнёт падать с ошибкой `Out of memory`,
  придётся перейти на платный план ($7/мес) — код и настройки при этом не меняются.
- **Засыпание.** Render усыпляет бесплатный сервис после 15 минут без входящих запросов.
  Поэтому и встроен самопинг, и работает пинг из GitHub Actions. Если бот всё-таки поспит,
  он проснётся через ~50 секунд — но события, которые произошли за это время, он не увидит.
- **GitHub отключает расписание**, если репозиторий не изменялся 60 дней.
  Раз в пару месяцев зайдите в **Actions → Keep-alive → Enable workflow**.
- Бесплатный сервис не поддерживает SSH, масштабирование, постоянные диски и `docker exec`.
  Файлы внутри контейнера (логи, `src/logs`) при перезапуске стираются — это нормально,
  важные данные лежат в базе.

## Как обновлять бота

```bash
# изменить код, потом:
git add <изменённые файлы>
git commit -m "что изменил"
git push
```

Render сам заметит пуш и пересоберёт сервис (2–5 минут). Ничего вручную нажимать не нужно.
Прогресс — в Render → **Deploys**.

## Как поменять токен бота или ключи

Render → сервис `yuuki-bot` → **Environment** → правьте нужное значение → **Save changes** →
**Manual Deploy → Deploy latest commit**. Изменение переменной само по себе не перезапускает бота.

Секреты хранятся двумя копиями: в Render (для облака) и в файле `.env` на компьютере (для локального
запуска). Меняя ключ, обновите оба места. `.env` в репозиторий не попадает — так и должно быть.

## Если что-то сломалось

| Симптом | Что смотреть |
| --- | --- |
| Деплой падает на `Dockerfile: no such file` | Dockerfile не закоммичен. Проверьте `.gitignore`: он намеренно прячет всё, кроме `src/`, поэтому у файлов деплоя стоят исключения `!Dockerfile`, `!package-lock.json` и т. д. |
| Деплой падает на `npm ci` | `package-lock.json` не в репозитории или разошёлся с `package.json`. Локально выполните `npm install --package-lock-only` и закоммитьте. |
| В логах `Authentication failed` | Неверный `BOT_TOKEN` в Render → Environment. |
| В логах ошибка подключения к базе | Устаревший `DATABASE_URL` (например, сменился пароль Aiven). |
| Бот офлайн, но сервис `Live` | Render → **Logs**: смотрите последнюю ошибку. Часто это лимит памяти или упавший запрос к внешнему API. |
| Бот офлайн и сервис `Suspended` | Закончились 750 часов бесплатного плана — ждать следующего месяца или переходить на платный план. |

## Запуск бота на своём компьютере (если понадобится)

```bash
npm ci
cp .env.example .env     # и заполнить своими значениями
npm start
```

Локально healthcheck не поднимается: он включается только когда задан `PORT` (его задаёт Render).
